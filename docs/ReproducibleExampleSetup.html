Reproducible Setup Example

Authors

Yuchen Li

David Rach

Background

This quarto markdown document (.qmd) is used to setup a reproducible environment needed to run the “Little Spectral Course” .qmd files for use in unmixing. Separately, the rendered code chunks together create a Quarto website, which can then be deployed to GitHub pages so that others can access it via an url.

Getting Started

Checking for Directories

First, lets check the working directory for the presence of the reproducible example folders. If they are not found, the script will proceed to generate them for us.

WorkingDirectory <- getwd()

# Cytometry-in-R-style organizational folders

DataFolder <- file.path(WorkingDirectory, "data")
if (!dir.exists(DataFolder)){dir.create(DataFolder)}

OutputsFolder <- file.path(WorkingDirectory, "outputs")
if (!dir.exists(OutputsFolder)){dir.create(OutputsFolder)}

ImagesFolder <- file.path(WorkingDirectory, "images")
if (!dir.exists(ImagesFolder)){dir.create(ImagesFolder)}

RFolder <- file.path(WorkingDirectory, "R")
if (!dir.exists(RFolder)){dir.create(RFolder)}

# Yuchen's required folders

refcontrolsFolder <- file.path(WorkingDirectory, "ref controls")
 if (!dir.exists(refcontrolsFolder)){dir.create(refcontrolsFolder)}

afFolder <- file.path(WorkingDirectory, "af")
 if (!dir.exists(afFolder)){dir.create(afFolder)}

Dataset Retrieval

For this reproducible example, you can either provide your own .fcs files, or alternatively, use a small downsampled dataset used for the TRU-OLS/AutoSpectral walk-through in the Cytometry in R course. If you want to use the provided dataset, set the value below to “TRUE”.

RetrieveExternalDataset <- FALSE
# RetrieveExternalDataset <- TRUE
if (RetrieveExternalDataset == TRUE){

    if (!requireNamespace("httr", quietly = TRUE)) install.packages("httr")
    if (!requireNamespace("jsonlite", quietly = TRUE)) install.packages("jsonlite")

    library(httr)
    library(jsonlite)

    owner  <- "UMGCCCFCSR"
    repo   <- "CytometryInR"
    branch <- "main"

    FullStainedSamplesPath <- "course/community/TRU-OLS/data/samples"
    UnmixingControlPath <- "course/community/TRU-OLS/data/unmixing_controls"

    #####################
    #      Samples      #
    #####################

    SamplesFolder <- file.path(DataFolder, "samples")
    if (!dir.exists(SamplesFolder)){dir.create(SamplesFolder)}

    api_url <- sprintf(
    "https://api.github.com/repos/%s/%s/contents/%s?ref=%s",
    owner, repo, FullStainedSamplesPath, branch
    )

    resp <- GET(api_url)
    stop_for_status(resp)

    files <- fromJSON(content(resp, as = "text", encoding = "UTF-8"))

    for (i in seq_len(nrow(files))) {
    if (files$type[i] == "file") {
        dest <- file.path(SamplesFolder, files$name[i])
        download.file(files$download_url[i], destfile = dest, mode = "wb", quiet = TRUE)
        message("Downloaded: ", files$name[i])
    }
    }

    #####################
    # Unmixing Controls #
    #####################

    UnmixingControlsFolder <- file.path(DataFolder, "unmixing_controls")
    if (!dir.exists(UnmixingControlsFolder)){dir.create(UnmixingControlsFolder)}

        api_url <- sprintf(
    "https://api.github.com/repos/%s/%s/contents/%s?ref=%s",
    owner, repo, UnmixingControlPath, branch
    )

    resp <- GET(api_url)
    stop_for_status(resp)

At this point, within your working directory, you will have a data folder with subfolders for both samples and unmixing_controls. If you are providing your own .fcs files, please copy the corresponding raw .fcs files to their respective folders.

Install Required R Packages

Various R packages need to be installed in order to run the respective scripts and .qmd files. To facilitate installation, we can run the requireNamespace() function. This will check to see whether it is installed, and if not, install it.

# CRAN
if (!requireNamespace("dplyr", quietly = TRUE)) install.packages("dplyr")
if (!requireNamespace("ggplot2", quietly = TRUE)) install.packages("ggplot2")
if (!requireNamespace("stringr", quietly = TRUE)) install.packages("stringr")  
if (!requireNamespace("purrr", quietly = TRUE)) install.packages("purrr")     
if (!requireNamespace("data.table", quietly = TRUE)) install.packages("data.table")
if (!requireNamespace("pheatmap", quietly = TRUE)) install.packages("pheatmap")

# Bioconductor
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")
if (!requireNamespace("flowCore", quietly = TRUE)) BiocManager::install("flowCore")
if (!requireNamespace("ggcyto", quietly = TRUE)) BiocManager::install("ggcyto")

# GitHub
if (!requireNamespace("remotes", quietly = TRUE)) install.packages("remotes")
if (!requireNamespace("flowSpectrum",
 quietly = TRUE)) remotes::install_github("https://github.com/hally166/flowSpectrum")
Tip

An alternate approach would be to specify the environment setup via renv, which would avoid messing with users existing installations.

Take Away

At this point, we have the required folder structure needed to keep things organized, have had the opportunity to bring in the .fcs files we will be utilizing for unmixing, and ensured that any necessary packages are installed in our local environment.
